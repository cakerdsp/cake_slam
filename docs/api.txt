cake_slam API (modules only)

IMU
- Unified IMU sample type: ImuSample
  - fields: stamp, acc, gyr
  - used directly by both LIO (FusionMeasure.imu) and Vision (Estimator imuBuf)

LIO
- LioCore
  - Configure(config)
  - ProcessMeasurement(lidar_measure_group)
  - GetState() -> StatesGroup
  - SetState(state)
  - GetUndistortedCloud() -> PointCloudXYZI::Ptr
  - GetDownsampledCloud() -> PointCloudXYZI::Ptr
  - GetDownsampledWorldCloud() -> PointCloudXYZI::Ptr
  - GetEffectPoints() -> point-to-plane inlier list

Vision
- readParameters(config_path)
  - uses unified config.yaml keys under vision.*, imu.*, extrinsic.*, frame.*, time_offset.*
- Estimator
  - inputImuSample(sample)
  - inputImage(t, mono_image, lidar_candidates, lio_pose_prior)
  - getLatestState() -> StatesGroup
  - getUndistortedValidMask() -> CV_8UC1 mask

LiDAR-to-vision
- LidarVisualSelector
  - Configure(config)
  - SetExtrinsics(R_I_L, t_I_L, R_C_L, t_C_L)
  - Select(cloud_lidar, state, gray, valid_mask, camera) -> candidates
- LidarVisualCandidate
  - fields: pixel, depth, inv_depth, inv_depth_var, P_W_init,
    shi_tomasi_score, mask_radius
- LioPosePrior
  - timestamp, R_WB, p_WB, sqrt_information, valid

Unified state
- StatesGroup is the only internal state carrier for LIO and VIO.
