# 共享误差感知的多相机光度观测选择

本次用观测选择替换原来的方向性门控。LIO 和 VIO 都不再执行 `rho` 阈值过滤；新模块只在视觉更新前决定使用哪些 patch。选中的残差继续使用现有的光度似然、迭代状态更新、协方差更新与重置。

这是一套条件于名义地图的观测调度实现，不是 SLAM 联合协方差一致性修复。当前参考位姿/地图点的似然协方差上界保持原样，选择器不会为了降低 NEES 而修改它们。

## 配置与运行

三个多相机 YAML 已更新，默认值如下：

```yaml
vio:
  photometric_selection_en: true
  photometric_selection_shared_errors: true
  photometric_selection_candidate_budget: 600
  photometric_selection_patch_budget: 150
  photometric_selection_pixel_budget: 9600
  photometric_selection_max_refs: 3
  photometric_selection_reference_pixel_std: 1.0
  cross_camera_current_residual_en: false
```

| 参数 | 含义 |
|---|---|
| `photometric_selection_en` | 关闭后恢复无方向门控的原有视觉观测路径 |
| `photometric_selection_shared_errors` | 开启时按联合共享误差计算条件增量；关闭时保留每个候选相同的边缘噪声，仅忽略候选之间的相关性，用于公平消融 |
| `candidate_budget` | 每帧进入评分预遍历的候选槽位上限；按相机分配，按提取栅格顺序分层抽取并轮换相位 |
| `patch_budget` | 最终选择的 patch 数上限 |
| `pixel_budget` | 每次线性化、每个金字塔层的像素预算；每个入选 patch 按完整 `patch_size_total` 计费，不以压缩后的秩或部分有效像素数计费 |
| `max_refs` | 同一点、当前相机的参考备选上限；有待验证参考时可保留一个测试槽，其余用于已验证参考。测试槽不进入状态估计 |
| `reference_pixel_std` | 前端输入分辨率下的参考灰度像素噪声标准差，单位为灰度值；默认 1.0 是可配置模型参数，尚未通过设备噪声标定 |

预算约束针对实际优化中的 patch 集合。提取、可见性/光度质量检查以及选择预遍历也有计算开销，因此固定残差预算不等于固定整帧耗时。`candidate_budget` 限制评分预遍历，不限制此前提取阶段的全部候选检查。

`common.directional_update_en` 已失效；检测到旧键会打印警告，不能再用它标记 ON/OFF。旧的 drop/full 阈值及实现已移除。

本模块需要图像输入。当前 `mid360_mei_multi_cam.yaml` 的 `common.img_en: 0` 被保留；做新模块实验时需设置为 `1`。纯 LIO 不受新选择器开关影响。

`cross_camera_current_residual_en` 是额外的当前帧—当前帧残差，会在选定的参考 patch 之外重复利用当前图像。当前选择器不对这一残差族计费，故不允许同时开启。HILTI22 与 M2DGR 配置中的此项已改为 `false`，mid360 原本就是 `false`。跨相机**历史参考复用**仍由 `cross_camera_reference_en` 控制，未关闭。

## 执行流程

1. 保留既有可见性、遮挡、采样、NCC、光度误差与参考生命周期检查。通过质量检查的参考备选进入候选池。
2. 在视觉更新入口的同一个完整状态和先验下，从细到粗寻找每个候选可评分的最细有效层。评分预遍历不执行状态修正。
3. 复用实际残差的完整 Jacobian，包含已启用的曝光、速度、时偏和外参列。使用完整状态先验，最后只评价六维位姿边缘协方差的变化；不会把其他变量当作已知常量，也不重新加入已融合的 LiDAR Hessian。
4. 贪心选择单位像素成本下位姿边缘对数行列式下降最大的候选。每个点—当前相机最多选一个参考，每个当前相机的图像栅格最多选一个 patch。
5. 选择集合在整个金字塔和迭代更新内固定。后续投影失效或质量检查不通过可以使入选残差退出，但不会临时加入未选中的候选。
6. 所有选中残差走现有估计器，不再对状态方向施加第二次信息抑制。轨迹文件的数据列和协方差评估文件的数据列保持不变；评估文件头新增选择模式及预算信息。

多参考测试按“点—当前相机—本帧”合并地图点的测试结果：任一有效参考通过即记一次通过，全部失败才记一次失败。每个参考自身仍独立维护历史测试结果；未进入预遍历的候选不会被记成失败。地图点的潜在信息也不会因多个参考重复累加。地图质量模块的潜在信息与实际进入估计器的信息统计含义不同。

## 评分模型与计算

在鲁棒权重与独立噪声白化后，令候选残差满足条件模型

\[
r_j = H_j\delta x + \sum_k B_{jk}\eta_k+n_j,
\qquad \operatorname{Cov}(n_j)=I,\quad \operatorname{Cov}(\eta_k)=I.
\]

每个共享源只建立一个键；`B` 已包含该源的协方差平方根。两个候选的交叉协方差为共享键对应的 `B_i B_j^T` 之和。候选自身噪声还包含单位独立噪声。

已选集合为 S 时，候选 j 的条件 Jacobian 与条件噪声为

\[
\bar H_j=H_j-R_{jS}R_{SS}^{-1}H_S,\qquad
\bar R_j=R_{jj}-R_{jS}R_{SS}^{-1}R_{Sj}.
\]

以 \(A_j=\operatorname{chol}(\bar R_j)^{-1}\bar H_j\) 更新临时设计协方差

\[
P'=P-PA_j^T(I+A_jPA_j^T)^{-1}A_jP.
\]

评分为 \(\tfrac{1}{2c_j}[\log\det P_{pose}-\log\det P'_{pose}]\)。这里的 P 只存在于选择器，不会写回 `state->cov`。

实现按共享源的连通分量维护分块 Cholesky 和候选条件量缓存。每加入一个观测，只向缓存追加该观测的创新，避免对所有旧残差反复求解。候选评分只计算六维位姿块，获胜后才更新完整设计协方差。

相关噪声下，候选的条件收益可能增加。实现会重新评分，没有使用要求收益单调递减的 lazy greedy，也没有宣称次模近似保证。

## 共享误差来源与边界

- **平面中心。** 源码的 `SOURCE_RAYCAST_PLANE` 实际加入平面中心，而非射线—平面交点。平面拟合另存 `local_plane_var_`，仅累积测距误差 `var_nostate`，不加入扫描位姿误差。出生时以 `[0 I]` 将法向—中心的联合协方差投影到点坐标，保存完整的中心 3×3 协方差、平面 ID 与修订号。同一出生平面中心的观测共享该源，不用后来更新的平面替换历史几何。
- **扫描点。** `SOURCE_PG` 保存出生扫描的局部测量协方差，同一点的多个相机观测共享该源。扫描点并非由附近平面重新估计，不能直接替换成平面深度误差。两种来源互斥，不把同一来源重复加入点项和平面项；来源不明的候选不按“零几何误差”评分。
- **参考像素。** 按参考相机、原始时间戳及输入图像像素索引标识源。支持 raw、pull-exact 的两级插值、forward-splat 的归一化沉积及随后的支持图插值。双线性、双三次和 Lanczos-4 与前端采样约定一致。曝光缩放和 ZNCC 归一化 Jacobian 会传播到像素系数，重复像素的系数先相加。裁剪饱和处使用零导数，未建模裁剪拐点。

为控制矩阵规模，评分先投影到候选状态 Jacobian 的列空间，保留全部有效状态列。该投影对独立白噪声下的状态信息无损；对相关噪声，它定义了一个压缩的近似评分模型，因为被丢弃的纯噪声分量本可帮助辨识共享误差。条件更新对这个压缩模型计算，不能称为完整原始像素模型的精确互信息。

当前几何传播冻结名义仿射 warp，没有对平面法向引起的整个 warp 变化再次求导，因此没有建立同一平面上不同扫描点之间的法向误差共享，也没有把附近平面 ID 直接当作这些点的位置误差源。独立残差噪声沿用 `photometricNoiseCovariance()`；参考像素项在此评分模型上显式加入。当前图像不同点的重叠采样噪声、外部图像预处理引入的相关性、跨平面的扫描误差，以及当前状态—历史地图的联合相关性未建立。每栅格一个 patch 减少局部重复，但不等价于这些相关性都已消除。

## 输出与实验

加粗青色 `printf` 输出 `[ PHOTO SELECT ]`：

- `shared`：是否使用候选间共享误差。
- `candidates / selected`：可评分候选数与计划使用的 patch 数。
- `pixels`：计费像素数及上限。
- `cameras / geometry_sources / cross_refs`：入选相机数、几何共享源数、跨相机历史参考数。
- `score_gain`：模型预测的位姿边缘信息收益，只用于诊断选择器。
- `model_reject_levels`：局部协方差、采样来源或可用 Jacobian 等无法支持评分时的层级尝试拒绝数。
- `prepass_ms`：包含评分预遍历、共享源构造和贪心选择的耗时。

建议先跑同一 LIVO 序列的两组：保持 `photometric_selection_en: true` 及其余设置一致，只切换 `photometric_selection_shared_errors: false/true`。这才是相同候选、相同预算下检验共享误差选择逻辑的消融。

再增加 `photometric_selection_en: false`，用于检查整个观测调度模块的影响。关闭时回到原有提取/预算策略，不应把它直接称为与前两组同预算。

保存完整终端日志、轨迹文件和协方差评估文件。比较 ATE、预先固定时间跨度的 RPE、失败情况和总耗时的中位数/P95；若精度相当，应如实比较有效预算与实际耗时。`score_gain` 增大本身不证明定位改善。NEES 仍需真值、时间/坐标对齐及对应协方差，作为一致性补充，而非本模块必须降低的目标。
